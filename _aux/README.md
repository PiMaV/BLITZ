repo root minimal.

- **external_posts/** – social/marketing snippets (e.g. LinkedIn)
- **tests/** – pytest unit and integration tests

- [`converters/`](../../converters/) — format bridges → `.npy`
- [`EVT/`](../../EVT/) — EVT Sidecar (EVT3 → BLITZ via WOLKE contract)
